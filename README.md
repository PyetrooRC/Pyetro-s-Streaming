# Pyetro's Streaming — redirecionador

Página única que aponta para o endereço público atual do servidor.

O servidor local reescreve o `index.html` a cada inicialização, com a URL nova
do túnel, e publica aqui. O endereço desta página é o link fixo que se
compartilha; o destino muda por trás dele.

Aqui **não** existe mídia, catálogo, credencial ou qualquer configuração —
apenas o `index.html` com a URL pública.
